Implementation Plan - URL-Based Intelligent Question Answering Assistant
Build a production-ready Retrieval-Augmented Generation (RAG) web application using Streamlit, LangChain, FAISS, sentence-transformers, and the Gemini API.

Proposed Architecture & Structure
We will create the following files and directories in the workspace:

requirements.txt: Python package dependencies.
.env: Environment variables (e.g., GEMINI_API_KEY).
app.py: The main Streamlit user interface and application driver.
loaders/:
web_loader.py: Fetches and extracts content from URLs using BeautifulSoup4.
pdf_loader.py: Extracts text and page numbers from PDF files/bytes using PyMuPDF.
preprocessing/:
cleaner.py: Cleans raw HTML/text (removes boilerplate, navbars, ads, scripts).
chunker.py: Chunks the text into overlapping segments with metadata.
embeddings/:
embedding_model.py: Wraps sentence-transformers/all-MiniLM-L6-v2 or LangChain's HuggingFaceEmbeddings.
vectorstore/:
faiss_store.py: Handles creating, updating, saving, and loading the FAISS index.
rag/:
retriever.py: Searches the vector database and formats contexts.
prompt.py: Defines the system and user prompts.
qa_chain.py: Integrates Gemini API via LangChain or Google GenAI to generate answers with source citations.
services/:
summarizer.py: Creates executive summaries, bullet summaries, and key takeaways.
utils/:
helpers.py: Helper functions (e.g., URL validation, exporting chat).
logger.py: Logging configuration.
Technical Details & API Selection
LLM: We'll use google-genai or langchain-google-genai with gemini-2.5-flash or similar. Let's install langchain-google-genai and google-genai so we have robust, direct access to the latest free Gemini API.
Embeddings: sentence-transformers/all-MiniLM-L6-v2 via HuggingFaceEmbeddings (langchain-huggingface).
Vector DB: faiss-cpu via LangChain's FAISS wrapper.
HTML Parsing: BeautifulSoup4 + Requests.
PDF Parsing: PyMuPDF (pymupdf).
UI: Streamlit.

Verification Plan

We'll write a simple test script inside tests/ or check each module individually by running local scripts to ensure PDF loading, URL crawling, embeddings, FAISS storage, and Gemini API inference work correctly.
